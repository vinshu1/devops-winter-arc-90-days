# ❄️ 90-Day DevOps Winter Arc

> **Learn → Build → Break → Fix → Explain → Interview**

A 90-day hands-on DevOps engineering journey covering Linux, AWS, Docker, CI/CD, Kubernetes, Amazon EKS, Terraform, GitOps, Observability, DevSecOps and Production Engineering.

The goal is not just to learn tools. The goal is to build production-style projects, troubleshoot failures, understand architecture and explain engineering decisions clearly in interviews.

---

## 🎯 Goals

* Strengthen Linux and infrastructure fundamentals
* Build strong AWS cloud fundamentals
* Master Docker and containerization
* Build real CI/CD pipelines
* Learn Kubernetes and Amazon EKS
* Automate infrastructure using Terraform
* Implement GitOps with ArgoCD
* Build production observability
* Practice DevSecOps and Kubernetes security
* Develop system-design skills
* Build production-style DevOps projects
* Prepare for DevOps / Cloud / SRE interviews
